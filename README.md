# ✅ To-Do App

A simple and interactive **To-Do List Web Application** built using **HTML, CSS, and JavaScript**.
This project allows users to add tasks, mark tasks as completed, and manage their daily activities through a clean and easy-to-use interface.

## 🌐 Live Demo

👉 [View Live Website](https://palakchhajed19.github.io/To-Do-App/)

## 📌 Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 📝 Simple and user-friendly interface
* ⚡ Interactive functionality using JavaScript
* 📱 Responsive design
* 🌐 Deployed using GitHub Pages

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive layout
* **JavaScript** – Task management and interactive functionality
* **Git & GitHub** – Version control and project hosting
* **GitHub Pages** – Deployment

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/PalakChhajed19/To-Do-App.git
```

### 2. Open the project

Open the project folder in **Visual Studio Code**.

### 3. Run the application

Open `index.html` in your browser.

For development, you can also use the **Live Server** extension in VS Code.

## 🎯 Project Purpose

The purpose of this project is to build a simple task-management application while practicing fundamental front-end development concepts.

Through this project, I practiced:

* HTML page structure
* CSS styling and layouts
* JavaScript DOM manipulation
* Event handling
* Adding and removing HTML elements dynamically
* Managing user interactions
* Deploying a website using GitHub Pages
